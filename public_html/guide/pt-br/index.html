O Que Você Pode Fazer

📁

Construir um Corpus

Envie PDFs, CSVs ou cole textos diretamente. Gerencie múltiplas fontes em um só lugar.

💬

Chat IA com Citações

Claude AI pesquisa seu corpus e responde com números de página das citações.

🔗

Incorporar com Uma Linha

Adicione uma única tag script a qualquer site existente e o widget de chat aparece.

Primeiros Passos (Operadores)

Da instalação ao widget ao vivo em 4 passos.

1

Instalação

Baixe o ZIP e envie para public_html. Abra o instalador web e insira as configurações do banco de dados.

2

Configurar Chave API LLM

Abra Configurações → LLM e insira sua chave API Anthropic. Use o teste de conexão para verificar.

3

Adicionar uma Fonte

Envie um PDF, CSV ou texto no painel Fontes. Após o processamento, o chatbot pode responder a partir dele.

4

Incorporar o Widget

Copie o código de incorporação de Configurações → Design e cole logo antes de </body> na sua página.

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

Usando o Widget de Chat

O widget de chat está pronto em 3 passos simples.

1

Abrir o Widget

Clique no ícone de chat no canto inferior direito da página para abrir o widget.

2

Digite sua Pergunta

Digite sua pergunta e pressione Enviar ou Enter.

3

Receber Resposta Citada

A IA pesquisa o corpus e responde com os números das páginas das fontes.

Perguntas Frequentes

Qual modelo de IA é usado? +
NeNe Corpus usa a API Claude da Anthropic (ex: claude-3-5-haiku ou claude-opus-4). Uma conta Anthropic e chave API são necessárias.
Quais formatos de arquivo são suportados? +
PDF, CSV e texto simples são suportados.
É gratuito? +
NeNe Corpus em si é código aberto sob Licença MIT. Os custos de uso da API Anthropic se aplicam separadamente.
Onde meus dados são armazenados? +
Todos os dados são armazenados no seu próprio banco de dados MySQL. Nada é enviado externamente, exceto solicitações de inferência LLM.
