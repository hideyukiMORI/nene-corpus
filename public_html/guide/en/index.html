For Operators

Getting Started (Operators)

From install to live widget in 4 steps — works on shared hosting and Docker alike.

1

Install

Download the release ZIP and upload it to public_html. Open the web installer and enter your database credentials. Setup complete.

2

Configure LLM API Key

Open Settings → LLM and enter your Anthropic API key. Use the connection test to verify before saving.

3

Add Sources

Upload PDFs, CSVs, or paste text in the Sources panel. Once ingested, the chatbot can answer from them. Manage multiple sources in parallel.

4

Embed the Widget

Copy the embed code from Settings → Design and paste it just before </body>. That's all it takes to go live.

Embed code (copy from Settings → Design)

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

For End Users

Using the Chat Widget

The widget is intuitive. Here's how it works in 3 steps.

1

Open the Widget

Click the chat icon in the bottom-right corner of the page.

2

Type and Send

Enter your question in natural language and press Send or hit Enter.

3

Get a Cited Answer

The AI searches the corpus and replies with source page numbers. Click a citation to jump to the source.

FAQ

Which AI model does it use? +
NeNe Corpus uses Anthropic's Claude API (claude-3-5-haiku, claude-opus-4, etc.). The model can be changed in the admin panel. An Anthropic account and API key are required.
What file formats are supported? +
PDF (with text layer), CSV, and plain text are supported. Scanned-image-only PDFs without a text layer are not supported.
Is it free? +
NeNe Corpus itself is open source under the MIT License. Anthropic API usage costs apply separately. See Anthropic's pricing page for details.
Where is my data stored? +
All corpus data and chat history are stored in your own database on your server. Chat queries are sent to the Anthropic API for AI inference.
Does it work on shared hosting? +
Yes. Any server with PHP 8.2+ and MySQL works. Deploy via FTP without SSH.
How can I improve answer accuracy? +
Adding high-quality source documents is the most effective approach. You can also customize the system prompt and manage costs via usage limits.
