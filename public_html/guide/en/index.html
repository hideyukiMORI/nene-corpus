Getting Started (Operators)

From install to live widget in 4 steps.

1

Install

Download the ZIP and upload it to public_html. Open the web installer and enter your database settings.

2

Configure LLM API Key

Open Settings → LLM and enter your Anthropic API key. Use the connection test to verify.

3

Add a Source

Upload a PDF, CSV, or paste text in the Sources panel. Once ingested, the chatbot can answer questions from it.

4

Embed the Widget

Copy the embed code from Settings → Design and paste it just before </body> on your page.

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

Using the Chat Widget

The chat widget is ready in 3 simple steps.

1

Open the Widget

Click the chat icon in the bottom-right corner of the page to open the chat widget.

2

Type Your Question

Enter your question and press Send or hit Enter.

3

Get a Cited Answer

The AI searches the corpus and replies with source page numbers.

FAQ

Which AI model does it use? +
NeNe Corpus uses Anthropic’s Claude API (e.g. claude-3-5-haiku or claude-opus-4). An Anthropic account and API key are required.
What file formats are supported? +
PDF, CSV, and plain text are supported.
Is it free? +
NeNe Corpus itself is open source under the MIT License. Anthropic API usage costs apply separately.
Where is my data stored? +
All data is stored in your own MySQL database. Nothing is sent externally except LLM inference requests.
