For Operators

快速开始（管理员）

从安装到上线 Widget，只需 4 步——适用于共享主机和 Docker。

1

安装

下载发布版 ZIP 并上传到 public_html。打开网页安装向导，输入数据库凭据。设置完成。

2

配置 LLM API 密钥

打开设置 → LLM，输入 Anthropic API 密钥。保存前使用连接测试进行验证。

3

添加数据源

在数据源面板上传 PDF、CSV 或文本。处理完成后，聊天机器人即可从中回答问题。

4

嵌入组件

从设置 → 设计选项卡复制嵌入代码，粘贴到页面 </body> 之前。完成。

嵌入代码（从设置 → 设计选项卡复制）

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

For End Users

使用聊天组件

聊天组件操作直观，3 步即可上手。

1

打开组件

点击页面右下角的聊天图标。

2

输入并发送

用自然语言输入问题，按发送或回车键。

3

获得带引用的回答

AI 搜索语料库并附带来源页码进行回答。点击引用可跳转到来源。

注意：AI 生成的回答仅供参考。重要信息请务必查阅原始资料进行核实。

常见问题

使用哪个 AI 模型？ +
NeNe Corpus 使用 Anthropic 的 Claude API（claude-3-5-haiku、claude-opus-4 等）。模型可在管理面板更改。需要 Anthropic 账户和 API 密钥。
支持哪些文件格式？ +
支持 PDF（含文本层）、CSV 和纯文本。仅由扫描图像组成且不含文本层的 PDF 不受支持。
是否免费？ +
NeNe Corpus 本身是 MIT 许可证下的开源软件。Anthropic API 使用费用单独计算。
数据存储在哪里？ +
所有语料库数据和聊天历史存储在您服务器上的数据库中。聊天查询会发送到 Anthropic API 进行 AI 推理。
能在共享主机上运行吗？ +
可以。任何支持 PHP 8.2+ 和 MySQL 的服务器均可运行。通过 FTP 部署，无需 SSH。
如何提高回答准确性？ +
添加高质量源文档最为有效。您还可以自定义系统提示词，并通过使用限制管理费用。
