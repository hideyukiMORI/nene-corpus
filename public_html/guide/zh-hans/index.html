功能介绍

📁

构建语料库

上传 PDF、CSV 或直接粘贴文本。在一处管理多个数据源。

💬

带引用的 AI 问答

Claude AI 搜索语料库，并附带页码引用进行回答。

🔗

一行代码嵌入

只需在任何现有网站添加一行 script 标签，聊天组件即可显示。

快速开始（管理员）

从安装到上线 Widget，只需 4 步。

1

安装

下载 ZIP 并上传到 public_html。打开网页安装向导，输入数据库配置。

2

配置 LLM API 密钥

打开设置 → LLM，输入 Anthropic API 密钥。使用连接测试进行验证。

3

添加数据源

在"数据源"面板上传 PDF、CSV 或文本。处理完成后，聊天机器人即可从中回答问题。

4

嵌入组件

从设置 → 设计选项卡复制嵌入代码，粘贴到页面 </body> 标签之前。

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

使用聊天组件

3 个简单步骤即可使用聊天组件。

1

打开组件

点击页面右下角的聊天图标，即可打开聊天组件。

2

输入问题

输入您的问题，然后按发送按钮或回车键。

3

获得带引用的回答

AI 搜索语料库，并附带来源页码进行回答。

常见问题

使用哪个 AI 模型？ +
NeNe Corpus 使用 Anthropic 的 Claude API（如 claude-3-5-haiku 或 claude-opus-4）。需要 Anthropic 账户和 API 密钥。
支持哪些文件格式？ +
支持 PDF、CSV 和纯文本格式。
是否免费？ +
NeNe Corpus 本身是 MIT 许可证下的开源软件。Anthropic API 使用费用单独计算。
数据存储在哪里？ +
所有数据存储在您自己的 MySQL 数据库中。除 LLM 推理请求外，不向外部发送任何内容。
