Chat IA avec citations pour votre site web

Téléchargez des PDF, CSV ou du texte pour construire un corpus. Intégrez un widget de chat qui répond aux questions de vos visiteurs avec des références.

Ce que vous pouvez faire

📁

Construire un corpus

Téléchargez des PDF, CSV ou collez du texte directement. Gérez plusieurs sources en un seul endroit.

💬

Chat IA avec citations

Claude AI recherche dans votre corpus et répond avec les numéros de page.

🔗

Intégration en une ligne

Ajoutez une seule balise script à n'importe quel site et le widget de chat apparaît.

Démarrage (opérateurs)

De l'installation au widget en direct en 4 étapes.

1

Installation

Téléchargez le ZIP et envoyez-le dans public_html. Ouvrez l'installateur web et entrez les paramètres de base de données.

2

Configurer la clé API LLM

Ouvrez Paramètres → LLM et entrez votre clé API Anthropic. Vérifiez avec le test de connexion.

3

Ajouter une source

Téléchargez un PDF, CSV ou du texte dans le panneau Sources. Une fois ingéré, le chatbot peut répondre à partir de celui-ci.

4

Intégrer le widget

Copiez le code d'intégration depuis Paramètres → Design et collez-le juste avant </body> sur votre page.

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

Utiliser le widget de chat

Le widget de chat est prêt en 3 étapes simples.

1

Ouvrir le widget

Cliquez sur l'icône de chat en bas à droite de la page pour ouvrir le widget.

2

Saisir votre question

Entrez votre question et appuyez sur Envoyer ou sur Entrée.

3

Recevoir une réponse citée

L'IA recherche dans le corpus et répond avec les numéros de page des sources.

Questions fréquentes

Quel modèle IA est utilisé ? +
NeNe Corpus utilise l'API Claude d'Anthropic (par ex. claude-3-5-haiku ou claude-opus-4). Un compte Anthropic et une clé API sont requis.
Quels formats de fichiers sont pris en charge ? +
PDF, CSV et texte brut sont pris en charge.
Est-ce gratuit ? +
NeNe Corpus est open source sous licence MIT. Les coûts d'utilisation de l'API Anthropic s'appliquent séparément.
Où sont stockées mes données ? +
Toutes les données sont stockées dans votre propre base de données MySQL. Rien n'est envoyé en externe, sauf les requêtes d'inférence LLM.
