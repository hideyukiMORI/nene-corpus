For Operators

Démarrage (opérateurs)

De l'installation au widget en direct en 4 étapes — fonctionne sur hébergement mutualisé et Docker.

1

Installation

Téléchargez le ZIP de publication et envoyez-le dans public_html. Ouvrez l'installateur web et entrez vos identifiants de base de données. Configuration terminée.

2

Configurer la clé API LLM

Ouvrez Paramètres → LLM et entrez votre clé API Anthropic. Effectuez un test de connexion avant de sauvegarder.

3

Ajouter des sources

Téléchargez des PDF, CSV ou du texte dans le panneau Sources. Une fois traités, le chatbot peut répondre à partir de ceux-ci.

4

Intégrer le widget

Copiez le code d'intégration depuis Paramètres → Design et collez-le juste avant </body>. C'est tout.

Code d'intégration (copier depuis Paramètres → Design)

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

For End Users

Utiliser le widget de chat

Le widget est intuitif. Voici comment il fonctionne en 3 étapes.

1

Ouvrir le widget

Cliquez sur l'icône de chat en bas à droite de la page.

2

Saisir et envoyer

Entrez votre question en langage naturel et appuyez sur Envoyer ou Entrée.

3

Recevoir une réponse citée

L'IA recherche dans le corpus et répond avec les numéros de page des sources. Cliquez sur une citation pour accéder à la source.

Note : Les réponses générées par l'IA sont à titre de référence uniquement. Vérifiez toujours les informations importantes dans les sources primaires.

Questions fréquentes

Quel modèle IA est utilisé ? +
NeNe Corpus utilise l'API Claude d'Anthropic (claude-3-5-haiku, claude-opus-4, etc.). Le modèle peut être changé dans le panneau admin. Un compte Anthropic et une clé API sont requis.
Quels formats de fichiers sont pris en charge ? +
PDF (avec couche de texte), CSV et texte brut sont pris en charge. Les PDF composés uniquement de scans sans couche de texte ne sont pas supportés.
Est-ce gratuit ? +
NeNe Corpus est open source sous licence MIT. Les coûts d'utilisation de l'API Anthropic s'appliquent séparément.
Où sont stockées mes données ? +
Toutes les données du corpus et l'historique des chats sont stockés dans la base de données sur votre serveur. Les requêtes de chat sont envoyées à l'API Anthropic pour l'inférence IA.
Fonctionne-t-il sur hébergement mutualisé ? +
Oui. Tout serveur avec PHP 8.2+ et MySQL fonctionne. Déployez par FTP sans SSH.
Comment améliorer la précision des réponses ? +
Ajouter des documents sources de haute qualité est le plus efficace. Vous pouvez aussi personnaliser le prompt système et gérer les coûts via les limites d'utilisation.
