For Operators

Erste Schritte (Betreiber)

Von der Installation bis zum Live-Widget in 4 Schritten — funktioniert auf Shared Hosting und Docker.

1

Installation

Release-ZIP herunterladen und in public_html hochladen. Web-Installer öffnen und Datenbank-Zugangsdaten eingeben. Setup abgeschlossen.

2

LLM-API-Schlüssel konfigurieren

Einstellungen → LLM öffnen und Anthropic-API-Schlüssel eingeben. Verbindungstest vor dem Speichern durchführen.

3

Quellen hinzufügen

PDFs, CSVs oder Text im Quellen-Panel hochladen. Nach der Verarbeitung kann der Chatbot daraus antworten. Mehrere Quellen parallel verwalten.

4

Widget einbetten

Einbettungscode aus Einstellungen → Design kopieren und direkt vor </body> einfügen. Fertig.

Einbettungscode (aus Einstellungen → Design kopieren)

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

For End Users

Chat-Widget verwenden

Das Widget ist intuitiv. So funktioniert es in 3 Schritten.

1

Widget öffnen

Chat-Symbol unten rechts auf der Seite anklicken.

2

Eingeben und Senden

Frage in natürlicher Sprache eingeben und Senden drücken oder Enter betätigen.

3

Antwort mit Zitaten erhalten

Die KI durchsucht das Corpus und antwortet mit Quellenseitenzahlen. Auf ein Zitat klicken, um zur Quelle zu springen.

Hinweis: KI-generierte Antworten dienen nur als Referenz. Überprüfen Sie wichtige Informationen stets anhand der Primärquellen.

Häufige Fragen

Welches KI-Modell wird verwendet? +
NeNe Corpus verwendet die Anthropic Claude API (claude-3-5-haiku, claude-opus-4 usw.). Das Modell kann im Admin-Panel geändert werden. Ein Anthropic-Konto und API-Schlüssel sind erforderlich.
Welche Dateiformate werden unterstützt? +
PDF (mit Textebene), CSV und Klartext werden unterstützt. Nur aus gescannten Bildern bestehende PDFs ohne Textebene werden nicht unterstützt.
Ist es kostenlos? +
NeNe Corpus selbst ist Open Source unter der MIT-Lizenz. Anthropic-API-Nutzungskosten fallen separat an.
Wo werden meine Daten gespeichert? +
Alle Corpus-Daten und der Chatverlauf werden in der Datenbank auf Ihrem Server gespeichert. Chat-Anfragen werden für die KI-Inferenz an die Anthropic-API gesendet.
Funktioniert es auf Shared Hosting? +
Ja. Jeder Server mit PHP 8.2+ und MySQL funktioniert. Deployment per FTP ohne SSH.
Wie kann ich die Antwortgenauigkeit verbessern? +
Das Hinzufügen hochwertiger Quelldokumente ist am effektivsten. Sie können auch den Systemprompt anpassen und Kosten über Nutzungslimits verwalten.
