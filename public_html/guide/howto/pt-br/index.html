Olá! Eu sou a Sakura e administro o Café Sakura. Queria adicionar um chat de IA ao meu site para que os visitantes possam tirar dúvidas a qualquer hora. Vamos fazer isso juntos!

Pronto em 4 Passos

Siga a Sakura da instalação até a publicação do widget.

1

Instalar

S
Primeiro você só faz o upload dos arquivos para o servidor. Parece técnico, mas dá para fazer pelo FTP — sem programar! 😊
  • 1 Baixe o ZIP mais recente do GitHub Releases
  • 2 Extraia o ZIP e envie o conteúdo para public_html
  • 3 Abra https://seu-dominio.com.br/install no navegador
  • 4 Informe os dados do banco de dados e clique em "Executar Instalação"
2

Configurar Chave de API

S
Crie uma conta na Anthropic e obtenha uma chave de API. Com ela configurada, a IA entra em ação! ✨
  • 1 Crie uma conta na Anthropic (console.anthropic.com)
  • 2 Gere uma nova chave de API e copie-a
  • 3 Abra o Admin → Configurações → aba LLM
  • 4 Cole a chave, clique em "Testar Conexão" → "Salvar"
3

Adicionar Conteúdo

S
Só fazer upload do seu cardápio em PDF ou arquivo de FAQ. Isso vira a base de conhecimento da IA! 📄
  • 1 No painel Admin, clique em "Adicionar Conteúdo"
  • 2 Selecione seus arquivos PDF, CSV ou de texto e envie
  • 3 Aguarde o status mostrar "Concluído" (leva segundos a minutos)
  • 4 Cardápios, FAQs, info da loja — envie quantos arquivos quiser
4

Incorporar o Widget

S
Copie uma linha de código e cole no seu site! O chat vai ao ar na hora. 🎉
  • 1 Abra o Admin → Configurações → aba Design
  • 2 Copie o código da seção "Código de Incorporação"
  • 3 Cole-o logo antes do </body> no HTML do seu site
  • 4 Recarregue a página — um ícone de chat deve aparecer no canto inferior direito! 
<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>
