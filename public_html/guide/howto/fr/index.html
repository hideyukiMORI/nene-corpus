Bonjour ! Je suis Sakura et je gère le Café Sakura. Je voulais ajouter un chat IA sur mon site pour que les visiteurs puissent poser des questions à tout moment. Faisons-le ensemble !

Terminé en 4 étapes

Suivez Sakura de l'installation à la publication du widget.

1

Installer

S
D'abord, il faut juste déposer les fichiers sur le serveur. Ça semble technique, mais on peut tout faire avec FTP — sans coder ! 😊
  • 1 Téléchargez le dernier ZIP depuis GitHub Releases
  • 2 Décompressez le ZIP et déposez le contenu dans public_html
  • 3 Ouvrez https://votre-domaine.fr/install dans le navigateur
  • 4 Saisissez vos informations de base de données et cliquez sur « Installer »
2

Configurer la clé API

S
Créez un compte Anthropic et obtenez une clé API. Une fois configurée, l'IA est opérationnelle ! ✨
  • 1 Créez un compte sur Anthropic (console.anthropic.com)
  • 2 Générez une nouvelle clé API et copiez-la
  • 3 Ouvrez Admin → Paramètres → onglet LLM
  • 4 Collez la clé, cliquez « Tester la connexion » → « Enregistrer »
3

Ajouter du contenu

S
Déposez simplement votre menu PDF ou votre FAQ. C'est ça qui devient la base de connaissance de l'IA ! 📄
  • 1 Dans l'interface Admin, cliquez sur « Ajouter du contenu »
  • 2 Sélectionnez vos fichiers PDF, CSV ou texte et envoyez-les
  • 3 Attendez que le statut affiche « Terminé » (quelques secondes à minutes)
  • 4 Menus, FAQ, infos boutique — ajoutez autant de fichiers que nécessaire
4

Intégrer le widget

S
Copiez une seule ligne de code et collez-la sur votre site ! Le chat est en ligne. 🎉
  • 1 Ouvrez Admin → Paramètres → onglet Design
  • 2 Copiez le code dans la section « Code d'intégration »
  • 3 Collez-le juste avant </body> dans votre HTML
  • 4 Rechargez la page — une icône de chat apparaît en bas à droite ! 
<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>
