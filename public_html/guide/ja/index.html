あなたのコンテンツに、引用付き AI チャットを。

PDF・CSV・テキストをアップロードしてコーパスを作るだけ。埋め込みウィジェットで、訪問者の質問にリアルタイムで答えます。

はじめる → 管理画面を開く

できること

📁

コーパスを構築

PDF・CSV・テキストを直接アップロード。複数ソースをまとめて管理できます。

💬

引用付き AI チャット

Claude AI がコーパスから関連箇所を検索し、出典ページ番号付きで回答します。

🔗

1 行で埋め込み

既存のウェブサイトに script タグを 1 行追加するだけで、チャットウィジェットが表示されます。

はじめかた（管理者向け）

インストールからウィジェット公開まで 4 ステップで完了します。

1

インストール

ZIP をダウンロードして public_html へアップロード。ウェブインストーラーを開いて DB 接続情報を入力してください。

2

LLM API キーを設定

設定モーダル → LLM から Anthropic API キーを入力します。接続テストボタンで動作確認できます。

3

ソースを追加

「ソース」パネルから PDF・CSV・テキストをアップロード。取り込みが完了するとチャットで回答できるようになります。

4

ウィジェットを埋め込む

設定 → デザインタブの埋め込みコードをコピーして、既存ページの </body> 直前に貼り付けてください。

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

はじめかた（利用者向け）

チャットウィジェットは 3 ステップで使えます。

1

ウィジェットを開く

ページ右下のチャットアイコンをクリックすると、チャットウィジェットが開きます。

2

質問を入力する

気になることをそのまま入力して送信ボタン（または Enter キー）を押してください。

3

引用付きの回答を受け取る

AI が関連するページや資料を検索して、出典番号付きで答えます。

よくある質問

どの AI モデルを使いますか？ +
Anthropic の Claude API（claude-3-5-haiku または claude-opus-4 など）を使用します。利用には Anthropic アカウントと API キーが必要です。
対応ファイル形式は？ +
PDF・CSV・プレーンテキストに対応しています。
無料で使えますか？ +
NeNe Corpus 自体は MIT ライセンスの OSS です。Anthropic API の利用料は別途かかります。
データはどこに保存されますか？ +
すべてのデータはあなたのサーバー内の MySQL に保存されます。外部には送信されません（LLM への推論リクエストを除く）。
