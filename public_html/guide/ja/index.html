For Operators

はじめかた（管理者向け）

インストールからウィジェット公開まで 4 ステップ。共用ホスティングでも Docker でも同じ手順です。

1

インストール

リリース ZIP をダウンロードして public_html へアップロードします。ウェブインストーラーを開いて DB 接続情報を入力するだけでセットアップ完了です。

2

LLM API キーを設定

設定モーダル → LLM タブから Anthropic API キーを入力します。接続テストボタンで疎通を確認してから保存してください。

3

ソースを追加・取り込む

「ソース」パネルから PDF・CSV・テキストをアップロードします。取り込みが完了するとチャットで回答できる状態になります。複数ソースを並行して管理できます。

4

ウィジェットを埋め込む

設定 → デザインタブの埋め込みコードをコピーして、既存ページの </body> 直前に貼り付けてください。それだけで公開完了です。

埋め込みコード（設定 → デザインタブからコピーできます）

<script
  src="https://your-domain.com/widget.js"
  data-nene-corpus
></script>

For End Users

はじめかた（利用者向け）

ウィジェットは直感的に使えます。3 ステップで使い方がわかります。

1

ウィジェットを開く

ページ右下のチャットアイコンをクリックすると、チャットウィジェットが開きます。

2

質問を入力して送信

気になることをそのまま自然な言葉で入力して、送信ボタン（または Enter キー）を押してください。

3

引用付きの回答を受け取る

AI が関連するページや資料を検索して、出典番号付きで答えます。番号をクリックすると元の資料ページに飛べます。

※ AI の回答は参考情報です。重要な判断には必ず一次資料を確認してください。

よくある質問

どの AI モデルを使いますか？ +
Anthropic の Claude API（claude-3-5-haiku、claude-opus-4 など）を使用します。利用モデルは管理画面から変更できます。利用には Anthropic アカウントと API キーが必要です。
対応ファイル形式は？ +
PDF・CSV・プレーンテキストに対応しています。PDF はテキストレイヤーが含まれているものが対象です（スキャン画像のみの PDF は非対応）。
無料で使えますか？ +
NeNe Corpus 自体は MIT ライセンスの OSS です。Anthropic API の利用料は別途かかります。料金は Anthropic の公式ページをご確認ください。
データはどこに保存されますか？ +
すべてのコーパスデータ・チャット履歴はオペレーターのサーバー上のデータベースに保存されます。チャットの問い合わせ内容は AI 推論のため Anthropic API に送信されます。
共用ホスティング（レンタルサーバー）でも動きますか？ +
はい。PHP 8.2+ と MySQL が使えるレンタルサーバーであれば動作します。SSH 不要で FTP だけでデプロイできます。
チャット回答の精度を上げるには？ +
質の高い文書をソースに追加することが最も効果的です。システムプロンプトのカスタマイズや、利用制限設定でコスト管理も行えます。
