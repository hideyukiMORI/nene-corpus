## 修正内容

### 1. `05-03 / 05-04`: title input セレクタ

| Before | After |
|--------|-------|
| `input[name="title"], input[id*="title"]` | `form.space-y-3 input[type="text"]` |

**原因:** `SourceDocumentsPanel` の title input には `name` も `id` も付いていない。
`form input[type="text"]` でも IngestionPanel の Source name input（`form.space-y-4`）が先にマッチしていた。

**修正:** document detail フォームの CSS クラス `space-y-3`（ingestion は `space-y-4`）で区別。

### 2. `05-09`: chunks mock の LIFO 優先順序バグ

**原因:** `setupDocumentsPanel` が後から `**/admin/documents/*/chunks` (空配列) を登録するため、
先に登録した実データ mock が LIFO で上書きされていた。

**修正:** chunks mock の登録を `setupDocumentsPanel` 呼び出し**後**に移動。

### 3. `03-10`: CSV ingest 成功メッセージが表示されない

**根本原因（コンポーネントバグ）:** `resetPreview()` が `setSuccess(null)` を呼んでいたため、
React 18 のバッチ更新により `handleIngest()` 成功後の `setSuccess(...)` と
`handleFileChange(null) → resetPreview()` が同一 render でキャンセルし合っていた。

**コンポーネント修正 (`IngestionPanel.tsx`):**
- `resetPreview()` から `setSuccess(null)` を除去
- `handleFileChange(next !== null)` で明示的に `setSuccess(null)` を呼ぶ
- `switchMode()` で明示的に `setSuccess(null)` を呼ぶ

**テスト修正 (`03-ingestion.spec.ts`):**
- `input[type="checkbox"][value="description"]` → `getByRole('group', { name: /Content columns/i }).getByLabel('description')`
  （チェックボックスに `value` 属性なし、かつ Metadata columns にも同名ラベルが存在）
