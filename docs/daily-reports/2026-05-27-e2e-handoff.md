## 残り4件の失敗内容と原因

### 1. `05-03` & `05-04`: title input selector が間違い

**現在のコード:**
```typescript
page.locator('input[name="title"], input[id*="title"]').first()
```

**問題:** `SourceDocumentsPanel.tsx` の title input には `name` も `id` も付いていない:
```html
<input class="nc-input mt-1" type="text" value={title} required />
```

**修正方法:** `05-documents.spec.ts` の 05-03, 05-04 で使っているセレクタを変更:
```typescript
// Before
page.locator('input[name="title"], input[id*="title"]').first()
// After
page.locator('form input[type="text"]').first()
// (検索フォームは type="search" なので競合しない)
```

### 2. `05-09`: chunks mock の LIFO 優先順序バグ

**問題:** test 05-09 は自前の chunks mock (`{ chunk_id:1, ... }`) を `setupDocumentsPanel` より前に登録する。
しかし `setupDocumentsPanel` が後で `**/admin/documents/*/chunks**` (空配列) を登録するため、
LIFO 順序で空配列が優先され、チャンクが表示されない。

**修正方法:** test 05-09 で chunks mock を `setupDocumentsPanel` 呼び出し**後**に再登録する:
```typescript
// 05-09 の修正
await setupDocumentsPanel(page);

// setupDocumentsPanel の general chunks mock より後に登録 (LIFO で優先される)
await page.route('**/admin/documents/1/chunks', (route) =>
  route.fulfill({ status: 200, contentType: 'application/json', body: JSON.stringify(chunks) }),
);

await page.locator('text=Document Alpha').first().click();
```

同様に 05-03, 05-04 の `page.route('**/admin/documents/1', ...)` も `setupDocumentsPanel` 後に移動が必要。

### 3. `03-10`: CSV ingest success が表示されない

**現象:** select fix 後も `.text-emerald-700` が表示されない  
**調査状況:** 未確定。可能性:
- `readFileAsBase64` は FileReader API を使う — Playwright headless で動作するはずだが未確認
- `onUploaded()` callback が sources リストを再取得するが、その mock が複数ルート競合している可能性
- `handleIngest` が成功後 `handleFileChange(null)` + `setName('')` を呼んで state リセットするが、
  その前に `setSuccess(...)` が呼ばれるはずなので影響ないはず
- ブラウザコンソールエラーを trace で確認すること: `npx playwright show-trace test-results/.../trace.zip`
