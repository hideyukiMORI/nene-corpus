## 課題・気づき

| 項目 | 内容 |
| --- | --- |
| **GUI の見え方** | API だけ先にできているわけではなく GUI も merge 済み。独立ページではなく Sources 表内の展開 UI |
| **8080 vs 5173** | 静的ビルド（`public_html/admin`）は古い JS のまま。`:8080` 利用時は `npm run build:release --prefix frontend` が必要 |
| **テーブル UX** | 長いソース名で横スクロールしないと「ドキュメント」列が見えにくい |
| **スケール** | 一覧 API は `limit`/`offset` のみ（default 100、`total` なし）。数千〜数万件ではページング・検索が必要 |
| **編集 UX** | 行展開 + 右ペインだと行数が多いとき編集フォームが画面下に出て DX が悪い → モーダル/ドロワー検討 |
